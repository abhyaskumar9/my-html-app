❓ Google Client ID Kaise Banayein? (Step-by-Step Guide)
Step 1: Project Banayein
Upar wale link par jayein $\rightarrow$ Top bar me Select Project / New Project par click karke naam 'RentManager' dalein aur Create karein.

Step 2: Consent Screen
Left menu me OAuth consent screen $\rightarrow$ External chunein $\rightarrow$ App name & Email bharein aur Save karein.

Step 3: Client ID Create Karein
Left menu me Credentials $\rightarrow$ + Create Credentials $\rightarrow$ OAuth client ID $\rightarrow$ Application type me Web application chunein aur Create dabayein.

Step 4: Paste Karein
Jo Client ID (xxxx.apps.googleusercontent.com) aayegi, use copy karke niche box me daalein.
